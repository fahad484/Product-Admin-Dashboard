# Product Admin Dashboard

A responsive product administration dashboard built with React, Vite,
Tailwind CSS and Axios using the DummyJSON API.

## Live Demo

https://your-project.vercel.app

## GitHub Repository

https://github.com/fahad484/Product-Admin-Dashboard

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Axios
- DummyJSON API

## Features

- Login page
- Protected routes
- Product listing
- Product search/filtering
- Product details
- Add product
- Edit product
- Delete product
- Responsive UI
- Toast notifications
